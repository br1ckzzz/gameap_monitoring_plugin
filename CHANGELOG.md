# Changelog

Все важные изменения в проекте GameAP WebMonitoring документируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/), проект придерживается [Semantic Versioning](https://semver.org/).

## [1.0.8] - 2026-09-28

### Важное (Major Highlights)
- **Персистентная аналитика кликов и переходов (Click & Connect Analytics):**
  - **Надёжное хранилище в БД:** счётчики кликов перенесены из эфемерной оперативной памяти плагина в постоянную конфигурацию `PluginSettings.click_stats`, сохраняемую в базе данных GameAP. Статистика больше не сбрасывается при перезапуске/пересоздании инстанса WASM.
  - **Отказоустойчивый сбор метрик:** маяк `trackServerClick` в `app.js` теперь передаёт `server_id` как в query-параметрах, так и в теле JSON через `Blob` для `navigator.sendBeacon` с fallback на `fetch(keepalive: true)`. В роутере плагина поддержаны все варианты путей (`/stats/click`, `/stats`, `action=click`, `action=stats/click`).
- **Синхронизация и сохранение положения спойлеров админ-панели:**
  - Состояние развёрнутых/свёрнутых карточек настроек (`open_sections`) теперь сохраняется на двух уровнях: мгновенно в локальном хранилище браузера (`localStorage: web_monitoring_admin_open_sections`) для открытия без задержек и на сервере в настройках плагина для кросс-девайсной синхронизации.
- **Единый стиль и адаптивный контраст кнопок «Развернуть / Свернуть»:**
  - Устранена ошибка засвечивания («белый текст на салатовом фоне») в светлой теме: удалена некорректная зависимость от системного `prefers-color-scheme`, переопределявшая тему интерфейса из ОС.
  - Все спойлеры интерфейса (секции настроек, алерт DDoS, инструкции Nginx/Caddy) приведены к единому стилю `.wm-spoiler-toggle` с состоянием `.is-open`. В светлой теме кнопке задан глубокий высококонтрастный лесной цвет `#166534` (соответствие WCAG AAA), в тёмной — чистый белый текст `#ffffff` с неоново-лаймовым шевроном `#a3e635`.
- **Редизайн таблицы статистики в панели управления:**
  - В тёмной теме устранён тёмно-серый цвет названий серверов — теперь они выводятся контрастным цветом `var(--wm-text) !important` (`#ffffff`).
  - Добавлена автоматическая сортировка серверов по популярности (топ кликов сверху), нумерация позиций (`#`), иконки серверов, бейджи игры/категории, стильные пилюли кликов и визуальный прогресс-бар доли переходов (`%`).
  - В шапку секции добавлен суммарный счётчик переходов («Всего кликов: X»).
- **Интерактивный баннер анонсов с таймером обратного отсчёта (Announcement Banner with Countdown Deadline):**
  - **Гибкая конфигурация событий:** возможность вывода привлекающего внимание баннера над списком серверов для оповещения игроков о турнирах, вайпах, техработах или акциях с тремя стилями: `Информация` (синий), `Предупреждение / Вайп` (оранжевый), `Успех / Событие` (зелёный).
  - **Таймер обратного отсчёта в реальном времени:** поддержка даты и времени дедлайна (ISO 8601). В баннере отображается живой секундный таймер обратного отсчёта (дни, часы, минуты, секунды), автоматически обновляющийся без перезагрузки страницы.
  - **Кнопка действия и ссылка:** опциональная кнопка «Подробнее» со ссылкой на новость, пост ВКонтакте или канал в Discord.
  - **Живой предпросмотр (Live Preview) в админке:** администратор видит реальный вид баннера и работу таймера прямо во время редактирования полей.
  - **Защита от мерцания при автообновлении:** устранено исчезновение и перезапуск таймера при фоновых периодических опросах списка серверов.
- **Очистка разметки офлайн-серверов:**
  - Полностью удалена избыточная кнопка-дубликат «Показать / скрыть офлайн-серверы» (`#hidden-servers-bar`), оставлен единственный компактный интерактивный аккордеон `#offline-accordion`.

### Исправлено (Fixed)
- **Устранение засветки кнопок в светлой теме:**
  - Исключено ложное срабатывание тёмной темы в панели управления из-за медиа-запроса `(prefers-color-scheme: dark)` при тёмной теме в ОС Windows. Определение темы теперь выполняется строго по реальным DOM-классам GameAP (`html.dark`, `data-theme="dark"`, `body.dark-mode`).
- **Поддержка Laravel CSRF в админ-панели:**
  - Запрос статистики кликов `loadClickStats` теперь в приоритетном порядке использует `window.axios` с автоматической передачей CSRF-токена админки GameAP.
- **Стабильность баннера анонсов:**
  - Устранено исчезновение и мерцание баннера анонсов при циклическом автообновлении списка серверов.

## [1.0.7] - 2026-09-25

### Важное (Major Highlights)
- **Визуальное оформление карточек серверов и библиотека обложек игр:**
  - **Интеграция библиотеки обложек игр (Game Covers):** автоматическое отображение официальных широкоформатных баннеров популярных игр (CS2, CS:GO, Counter-Strike 1.6, CS:Source, Team Fortress 2, Garry's Mod, Left 4 Dead 2, Rust, Valheim, ARK, 7 Days to Die, Killing Floor, Day of Defeat, Minecraft и др.) через стабильный CDN.
  - **Умный каскадный отказ (Silent Fallback):** плавное появление (`fade-in`) картинок только после завершения загрузки (`onload`). При отсутствии игры в базе или сбое сети активируется стилизованная фоновая заглушка карточки с гейминг-акцентом, полностью исключая отображение браузерных рамок битых файлов и текста `alt`.
  - **Специальный режим для выключенных серверов (OFFLINE):** карточки отключенных серверов отображают лаконичную приглушённую заглушку (`.card-hero.is-offline`), не создают паразитных сетевых запросов к внешним CDN и скрывают неактуальные элементы (кнопку подключения).
  - **Полная адаптация под светлую тему:** добавлены светлые градиентные заглушки для онлайн и оффлайн карточек, контрастные бейджи игр и бейджи статусов, устраняющие эффект «тёмных пятен» на светлом фоне страницы.

### Исправлено (Fixed)
- **Отображение кастомного подзаголовка мониторинга (Custom Subtitle):**
  - Устранена проблема, из-за которой кастомный подзаголовок, настроенный в админ-панели (поле «Подзаголовок»), безусловно перезаписывался статическим дефолтным переводом i18n при инициализации клиентского скрипта `app.js` и смене языка.
  - Добавлено корректное определение пользовательского подзаголовка и заголовка (`detectBrandingCustomizations`), поддержка инъекции в `window.INITIAL_DATA` на стороне WASM/Rust и `mock_server.py`, а также сохранение кастомных параметров в `initCustomBranding`.
- **Отображение графики карточек и устранение битых изображений:**
  - Устранены ошибки загрузки и браузерные рамки «битых» картинок: графика появляется плавно только после успешной загрузки, а при ошибке узел мгновенно заменяется на аккуратную заглушку карточки.
- **Заголовок страницы во вкладке браузера (Bug 5):**
  - Исправлен поиск тега `<title>` в `handlers.rs` для соответствия разметке `index.html`. Кастомный заголовок из настроек плагина теперь корректно отображается в названии вкладки браузера.
- **Очистка серверов-призраков при удалении всех серверов в GameAP (Bug 6):**
  - В `servers_client.rs` разграничены ошибка связи с хостом (`None`) и успешный ответ с нулевым количеством серверов (`Some(empty)`). При удалении всех серверов в панели плагин больше не воскрешает старые серверы из кэша настроек.
- **Устранение избыточного AJAX-запроса на старте страницы (Bug 7):**
  - В `app.js` оптимизирован стартовый цикл: если серверы уже предзагружены в HTML (`window.INITIAL_DATA`), мгновенный повторный запрос к `/servers` пропускается, снижая нагрузку на очередь плагина в GameAP.
- **Скрипт сборки `build.ps1` и Dockerfile (Bug 8):**
  - В `build.ps1` добавлено автоопределение GNU-тулчейна и проверка статуса сборки.
  - В `Dockerfile` добавлено копирование исходников `frontend/` и синхронизация ассетов перед компиляцией WASM.

### Добавлено (Added)
- **Динамический заголовок вкладки браузера (Idea 9):**
  - В `app.js` добавлен динамический индикатор в `document.title` со счётчиком онлайна и активной игрой (например, `(3/5 Online) GameAP Servers` или `(2/2 Counter-Strike 2) • GameAP Servers`).

## [1.0.6] - 2026-09-21

### Важное (Major Highlights)
- **Полная миграция ядра плагина на Rust (`wasm32-wasip1`):**
  - **Компактный размер:** итоговый размер бинарного модуля `.wasm` сокращён до ~390 КБ за счёт отказа от рантайма Go.
  - **Минимальное потребление памяти:** нулевой оверхед по RAM, отсутствие задержек на сборку мусора (GC) и мгновенный холодный старт в песочнице Wazero.
  - **Строгая надёжность:** гарантированная типобезопасность и предсказуемая производительность при высоких нагрузках.

### Исправлено (Fixed)
- **Критическая стабильность памяти WASM (устранение Heap Corruption и ошибки HTTP 500):**
  - Устранено накопительное разрушение кучи при долговременной непрерывной работе внешних сервисов и Discord-бота (решает проблему с `HTTP 500: plugin error` после сотен последовательных запросов).
  - Экспорт функций `allocate` и `deallocate` синхронизирован напрямую с `libc::malloc` и `libc::free` (`dlmalloc`). Достигнута 100% совместимость с механизмом освобождения буферов хост-рантаймом GameAP.
- **Маршрутизация HTTP-запросов и API для внешних систем:**
  - Реализована отказоустойчивая диспетчеризация запросов с поддержкой любых префиксов GameAP (`/`, `/settings`, `/servers`, `/api/servers`, `/api/plugins/monitoring/...`) и fallback-параметра `?action=`.
  - Устранена проблема со сбросом путей из-за специфики декодирования системного Base32 ID `monitoring` в ядре GameAP.
  - Предоставлен выделенный эндпоинт `/api/servers` для бесшовной интеграции с внешними мониторингами и Discord-ботом с поддержкой авторизационного заголовка `X-WebMon-Token`.
- **Интерфейс публичной страницы и обработка состояний (UI/UX):**
  - **Корректное разделение состояний списка серверов:** полностью удалены тестовые демо-данные (`DEMO_SERVERS`). Если активных серверов нет или они скрыты, интерфейс корректно отображает пустой список («Серверы не найдены»), а блок ошибки («Не удалось загрузить данные») активируется только при реальных сетевых сбоях.
  - **Устранение блокирующей ошибки фронтенда (`ReferenceError`):** исправлена ошибка `AUTO_REFRESH_SECONDS is not defined` в `app.js`, приводившая к остановке таймера обратного отсчёта и зависанию спиннера загрузки.
  - **Серверная инъекция конфигурации:** интервал автообновления и начальные данные теперь напрямую инжектируются в HTML-разметку при первичном серверном рендере.
- **Сохранение настроек плагина в базе данных GameAP:**
  - Устранена ошибка игнорирования параметров при сохранении конфигурации при пустом списке серверов (`cached_servers`).
  - Добавлены аннотации значений по умолчанию (`#[serde(default)]`) для всех ключевых полей структуры `PluginSettings`, исключающие сбои десериализации при обновлении со старых версий.

### Добавлено (Added)
- **Интеграция с Discord / Bot API в панели администратора:**
  - В интерфейс настроек добавлен блок конфигурации и информационный статус для связки с ботом GameAP WebMonBot.

## [1.0.5] - 2026-09-18

### Добавлено (Added)
- **Канонический короткий публичный URL без `/view`:**
  - Публичная страница мониторинга теперь доступна напрямую по адресу `/api/plugins/monitoring` (и `/api/plugins/monitoring/`).
  - Сохранена 100% обратная совместимость с адресом `/api/plugins/monitoring/view`.
  - В админ-панели и документации обновлены готовые шаблоны обратного прокси (Nginx, Caddy, Apache).
- **Интерактивный логотип на публичной странице:**
  - Логотип и заголовок в шапке стали кликабельной ссылкой: клик сбрасывает активные фильтры серверов и поиск, возвращая на главную страницу мониторинга.
- **Внутриплагинный RAM Micro-Cache (4 сек) и оптимизация под GameAP v4.5.3:**
  - Реализован быстрый in-memory кэш данных `FetchPublicServers` в памяти плагина на 4 секунды с автоматическим сбросом при сохранении настроек.
  - Предотвращает переполнение очереди запросов GameAP (`PLUGINS_ROUTES_MAX_QUEUE`) при одновременных обращениях множества пользователей.
- **Предзагрузка данных в HTML (Zero-latency Initial Render):**
  - Серверная инъекция `window.INITIAL_DATA` при отдаче HTML страницы обеспечивает мгновенное отображение списка серверов без ожидания первого AJAX-запроса.
- **Поддержка доверенного клиентского IP GameAP v4.5.3:**
  - В диагностическом эндпоинте `/diagnostic` задействован заголовок `X-Gameap-Client-Ip` для корректного отображения IP-клиента за прокси.

### Изменено (Changed)
- **Адаптация поведения фронтенда под DoS-защиту GameAP v4.5.3 (HTTP 429 / 503):**
  - При получении кодов ответа 429 (Too Many Requests) или 503 (Service Unavailable) фронтенд корректно учитывает заголовок `Retry-After`, выводит предупреждение о временной нагрузке и делает паузу вместо повторных каскадных запросов к резервным эндпоинтам.
  - Клиентский таймаут запроса серверов увеличен до 9.5 секунд для согласованности с серверным лимитом ожидания в очереди GameAP (`PLUGINS_ROUTES_QUEUE_TIMEOUT = 10s`).

## [1.0.3] - 2026-09-13

### Исправлено (Fixed)
- **Пустой список в блоке «Видимость серверов» админ-панели при доступе из внешней сети:**
  - **Причина:** В `admin_bundle.js` использовался устаревший путь `/plugins/web-monitoring/servers` (возвращавший 404 на рабочей панели GameAP). Резервный вызов `/api/servers` блокировался политикой CORS и отсутствием авторизационного токена при доступе через внешние домены, реверс-прокси или мобильные сети. Кроме того, эндпоинт `FetchPublicServers` в Go отфильтровывал скрытые серверы.
  - **Решение:**
    - В модуле Go реализована функция `FetchAllServers`, запрашивающая полный список серверов напрямую из ядра GameAP через `serversRepo.FindServers` без фильтрации скрытых серверов.
    - Ответ `GET /settings` дополнен полями `servers` и `all_servers`, что позволяет админ-панели гарантированно получать список серверов в том же первичном запросе настроек.
    - В `handleServers` добавлена поддержка флага `all=1` (`action=admin_servers`) для отдачи полного списка серверов для администратора.
    - Во фронтенде админ-панели (`admin_bundle.js`) внедрено мгновенное извлечение серверов из ответа настроек, выстроена цепочка резервных запросов к API плагина и обеспечено сохранение списка в `cached_servers`.

## [1.0.2] - 2026-09-13

### Исправлено (Fixed)
- **Ошибка `route not found` при открытии публичной страницы `/api/plugins/monitoring/view`:**
  - **Причина:** В ядре GameAP парсер Base32 (`pkg/plugin/id.go`) ошибочно пытается декодировать ID `monitoring` как число (все буквы слова входят в алфавит Base32). Из-за несовпадения битовой длины (50 бит у 10 символов base32 vs 48 бит у 6 байт) при обратном сжатии ID превращался в `monitorine`, из-за чего функция `extractPluginPath` в GameAP не могла отрезать префикс URL и сбрасывала путь на `/`.
  - **Решение:** В плагине зарегистрирован корневой fallback-маршрут `{ Path: "/", Methods: ["GET", "POST"] }` и реализована умная диспетчеризация запросов. При сбросе пути на `/` плагин корректно отдаёт публичную HTML-страницу мониторинга либо обрабатывает API-запросы по параметру `?action=...`.
- **Отказоустойчивость запросов API во фронтенде:**
  - В `app.js` и `admin_bundle.js` запросы к API дополнены параметрами действий (`?action=servers`, `?action=settings`) и резервной цепочкой fallback-эндпоинтов.
